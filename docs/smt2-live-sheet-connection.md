# SMT2 — เชื่อม Google Sheets จริงอย่างปลอดภัย

**สถานะ:** เตรียมโค้ดพร้อมทดสอบออฟไลน์ใน GitHub เท่านั้น **ยังไม่ได้ติดตั้งหรือ Deploy ไปยัง Apps Script จริง** และยังไม่ได้แก้ไขข้อมูลใน Google Sheets

## แหล่งข้อมูลที่ตรวจสอบแล้ว

- ชื่อไฟล์ต้นฉบับ: สมท 2 (2568) — ยืนยันว่าเข้าถึงผ่าน Google Sheets connector ได้
- ชีตเจ้าหน้าที่: การะเกด, ชยาน์ขวัญ, ฉัตรพร, สกุลวรรณ, ภทรพงค์, ปิยะพงษ์, เทอดพงศ์, โสภา
- ชีตอื่น: กลุ่มต่างด้าว, กลุ่มศาสนา, Config, OrgChart
- ชีตเจ้าหน้าที่ที่ตรวจหัวตารางมี ลำดับ, จังหวัด, เรื่อง, หมายเลขเอกสารสิทธิ ผู้ขอ/ผู้ร้อง, เลขที่หนังสือ, E-contact DC, ประเภท, สำนักฯ รับเรื่อง, เจ้าหน้าที่ รับเรื่อง, เจ้าหน้าที่รับผิดชอบ, สถานะปัจจุบัน, หมายเหตุ

## ขั้นตอนเจ้าของระบบ (จำเป็นก่อนเปิดใช้งาน)

1. สำรองโครงการ Apps Script เดิมและทบทวน Deployment ทุกตัว โดยเฉพาะตัวที่ตั้ง Execute as Me / Anyone
2. **จำกัดหรือปิด Deployment เดิมที่ยังเปิดให้ทุกคนเข้าถึง** ก่อนใช้ข้อมูลจริง เนื่องจาก `addRecord`, `updateRecord`, `getServerData`, `getUniqueColumnValues` และ `getCombinedDashboardData` ใน Code.gs เดิมยังไม่มีการตรวจสิทธิ์
3. สร้าง Apps Script deployment ที่จำกัดผู้ใช้ที่อนุญาตเท่านั้น และทดสอบ `Session.getActiveUser().getEmail()` กับบัญชีเจ้าหน้าที่จริง หากว่างต้องปฏิเสธการใช้งาน
4. นำ `smt2/backend/live-sheets-adapter.reference.gs` เข้าโครงการ Apps Script ที่จำกัดสิทธิ์ โดย **ไม่** เปิดให้ผู้ใช้สาธารณะเรียกใช้ และกำหนด Script Properties ฝั่งเซิร์ฟเวอร์ดังนี้:
   - `SMT2_SPREADSHEET_ID`: ID ของชีตต้นฉบับที่เจ้าของตรวจสอบ
   - `SMT2_READER_EMAILS`: อีเมลผู้มีสิทธิ์อ่าน คั่นด้วยจุลภาค
   - `SMT2_EDITOR_EMAILS`: อีเมลผู้มีสิทธิ์แก้ไข คั่นด้วยจุลภาค
   - `SMT2_ALLOWED_SHEETS`: รายชื่อชีตเจ้าหน้าที่ที่อนุญาตอย่างชัดเจน คั่นด้วยจุลภาค
   - `SMT2_READER_COLUMNS`: ชื่อคอลัมน์ที่อนุญาตให้ผู้อ่านเห็น **แนะนำเริ่มจาก** `ลำดับ,จังหวัด,สถานะปัจจุบัน` และให้ผู้ดูแลอนุมัติก่อนเพิ่ม
5. ทดสอบ `smt2LiveHealth`, `smt2LiveListSheets`, `smt2LiveReadPage` ในโครงการที่จำกัดสิทธิ์ด้วยบัญชีที่อนุญาตและไม่ได้อนุญาต
6. ปิด/เปลี่ยนฟังก์ชันเดิมที่ไม่มี guard ทุกตัวก่อนอนุญาตการอ่านรายเรื่องจาก UI และก่อนเปิดฟังก์ชันเขียน
7. เชื่อมหน้าเจ้าหน้าที่ที่โฮสต์ภายใน Apps Script ผ่าน `google.script.run` หลังทดสอบสิทธิ์แล้วเท่านั้น; **ไม่สามารถเรียก `google.script.run` จาก GitHub Pages**
8. การเผยแพร่สถิติสาธารณะต้องผ่านกระบวนการอนุมัติข้อมูลรวมและตรวจการเปิดเผยข้อมูลย่อย; ห้ามเผยแพร่ข้อมูลรายเรื่อง/อีเมลเจ้าหน้าที่/คีย์ผ่าน GitHub Pages

## ข้อจำกัดปัจจุบัน

- ไฟล์ adapter นี้เป็น **read-only** ไม่มีการแก้ไข Google Sheets
- ฟังก์ชัน adapter ปลอดภัยเฉพาะเมื่อไม่มี legacy global functions ที่เปิดช่องให้ข้ามการตรวจสิทธิ์ และ deployment ถูกจำกัดอย่างถูกต้อง
- ไม่มีการอ้างว่าผ่านการทดสอบกับบัญชีเจ้าหน้าที่หรือ Apps Script จริง
- การทดสอบ Node ใช้ mock Google Apps Script และข้อมูลสมมติ ไม่ใช่ข้อมูลจริง
- การเชื่อมหน้า UI กับ Apps Script จะดำเนินการหลังผ่าน security gate ข้างต้น
